# MIN-13 — Observação sem Julgamento (Mindful Observation)
## Protocol Origin
- **Source:** DBT Mindfulness "What" Skills — Observe (Linehan, 1993, 2015)
- **Also in:** MBSR (choiceless awareness), ACT (present-moment awareness)
## Clinical Protocol
**Type:** guided_script | **Duration:** 7 min
### Script Outline
1. **Choose object (1 min):** Select a natural object (leaf, flower, cloud, candle flame). Hold or observe it.
2. **Visual attention (2 min):** Notice colors, shapes, textures, light, shadow. As if seeing it for the first time.
3. **Expanding senses (2 min):** Notice weight, temperature, smell. What would it feel like to touch?
4. **Thoughts as weather (1 min):** When thoughts arise ("this is boring," "what's next"), notice them like passing clouds. Return to the object.
5. **Integration (1 min):** Widen awareness. Notice how you feel after sustained attention.
## Evidence Base
1. Linehan MM (2015). *DBT Skills Training Manual, 2nd Ed.* Guilford Press. — "Observe" as first Mindfulness "What" skill.
